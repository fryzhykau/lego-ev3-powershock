Controller

    Connect the controller

    Wireless, to this laptop. The laptop reads the controller and drives the brick. You do this once; after that, pressing PS reconnects it.

    1. Start with the controller off
      If the light bar is lit, hold PS (the round button in the middle) for about 10 seconds until it goes dark. Is a PS4 nearby and on? Switch it off first, or the controller goes back to it.
    2. Put it in pairing mode
      Hold Share (the small button left of the touchpad) and PS together for 3–5 seconds. Let go when the light bar flashes white in quick double blinks. A slow single pulse isn't pairing mode; try again. It keeps flashing for about a minute.
    3. Open Bluetooth on this laptop
      Start → Settings → Bluetooth & devices. Check Bluetooth is On, then Add device → Bluetooth. Open Bluetooth settings
    4. Pick “Wireless Controller”
      That's the DualShock 4's name in Windows. If it asks for a PIN, type 0000. Wait for “Your device is ready to go”: the light bar stops flashing and stays lit.
    5. Press any button on the controller, with this page open
      Browsers only see a controller after a button press. This step ticks itself when it works, and the status bar says DualShock 4.

    The quickest way, and it charges the controller too. Nothing to pair.

    1. Plug it in
      Use a micro-USB cable that carries data; some phone-charging cables only carry power. The socket is on the top edge of the controller, between L1 and R1.
    2. Press PS
      The light bar turns on. The first time, Windows sets it up by itself in a few seconds.
    3. Press any button on the controller, with this page open
      Browsers only see a controller after a button press. This step ticks itself when it works, and the status bar says DualShock 4.
    If it doesn't work
    • “Wireless Controller” isn't in the list. Pairing mode has timed out: hold Share + PS again until the double blinks, then look again.
    • It was paired before but won't connect. In Bluetooth & devices, open the ⋯ menu next to Wireless Controller → Remove device, then pair again from step 1.
    • It keeps going back to a PS4. A controller reconnects to the last thing it paired with. Pair it with the laptop again.
    • Connected in Windows, but this page shows nothing. Press a button while this page is open, and use Chrome or Edge.
    • Still stuck? Reset it: push a straightened paper clip into the small hole on the back, next to L2, for 5 seconds. Then pair again.

    Experimental: no laptop needed while driving, but untested, and some controllers refuse it. Uses the powershock-bt.jar program.

    1. Find the controller's address
      Pair it with Windows once (other tab), then Device Manager → Bluetooth → Wireless Controller → Properties → Details → Bluetooth device address. Put it in DS4_MAC in DS4Drive.java and upload.
    2. Remove it from Windows
      Otherwise it connects to the laptop instead of the brick.
    3. Start powershock-bt.jar on the brick
      Bluetooth must be on in the leJOS menu. The screen shows Share+PS to pair.
    4. Hold Share + PS
      Every time, until the brick screen says Connected!. An error with a number (errno) means the controller refused; stay with the laptop route.

              Sensors

                Seen by the camera

                  Robot size

                  The map works out where the robot is from how far its wheels turn, so these need to match your robot. Measure in millimetres.

                  The camera's height and tilt tell the map how far away things are, from where they meet the floor in the picture. The 3D view shows the camera on the robot, with lines to the corners of the floor it can see.

                  Distance is estimated from the wheels, so the map slowly drifts, especially after sharp turns or wheel slip. A gyro sensor keeps the heading straight. Clear map starts again from where the robot is.

                  Gearing

                  Trade speed for strength with standard LEGO gears
                  Small drives big: slower, stronger12 turning 36: the output turns 3× slower with about 3× the force. For lifting, climbing, arms.
                  Big drives small: faster, weaker36 turning 12: 3× faster, about ⅓ of the force. For fast cars on flat ground.
                  Speed × force stays the sameGears can't add power. Each pair loses about 10% to friction; a worm gear much more.
                  Spacing = (teeth + teeth) ÷ 16 studs12 + 36 = 3, 8 + 24 = 2, 24 + 40 = 4. Half studs (20 + 36 = 3.5) need offset holes.
